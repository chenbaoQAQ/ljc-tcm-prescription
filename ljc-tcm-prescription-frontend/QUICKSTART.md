# 快速上手指南

## 🚀 5分钟启动

### Step 1: 配置后端地址

打开 `config/env.js`，修改为你的后端地址：

```javascript
module.exports = {
  BASE_URL: 'http://192.168.1.7:8081'  // 改成你的IP
};
```

### Step 2: 导入微信开发者工具

1. 打开微信开发者工具
2. 导入项目 选择 `ljc-tcm-prescription-frontend` 目录
3. AppID 选"测试号"

### Step 3: 关闭域名校验

详情 → 本地设置 → 勾选 **不校验合法域名...**

### Step 4: 编译运行

点击"编译"即可！

## 🎯 核心功能说明

### 开病历流程

```
输入姓名 → 选日期 → 勾选药方 → 保存 → 自动合并药材
```

**合并规则：**
- 同名药材取最大克重（后端自动处理）
- 结果按药材名排序

### 常用场景

**场景1：给同一患者开多次病历**
1. 开病历后点"继续开一个"
2. 重新输入姓名（日期自动更新为今天）
3. 重新选择药方

**场景2：查看以往用药记录**
1. 首页 → "病历历史"
2. 输入患者姓名搜索
3. 点击记录查看详情
4. 可复制药材清单发送给患者

## ⚠️ 常见问题

### Q: 点击保存后提示"网络错误"？

**解决：**
1. 确认后端服务已启动
2. 浏览器访问 `http://localhost:8081/swagger-ui.html` 确认
3. 检查 `config/env.js` 里的IP地址

### Q: 药方编辑时选择器是空的？

**原因：** 还没添加药材

**解决：** 先去"药材库"添加几个药材

### Q: 为什么有的操作没反应？

**检查清单：**
- 是否勾选了"不校验域名"？
- 控制台是否有错误提示？
- 后端接口是否正常？

## 🔧 技术细节（给开发者）

### 数据流

```
前端（小程序）
  ↓ HTTP Request
后端API（SpringBoot）
  ↓ JPA
数据库（MySQL）
```

### 响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": { ... },
  "traceId": "xxx"
}
```

### 错误处理

所有 `code !== 0` 的响应会自动 toast 提示，无需手动处理。
