# 📱 手机访问指南

## ✅ 您的专属地址
**http://192.168.1.6:8081**

## 🚀 快速启动步骤

1. **确保电脑后端已启动**
   在终端运行：`./mvnw spring-boot:run`

2. **手机连 WiFi**
   确保手机和电脑连在同一个 WiFi 下

3. **访问测试**
   - 先用您自己的手机试一下，能打开说明配置成功！
   - 如果打不开，请检查电脑防火墙是否开启（Mac: 系统偏好设置 -> 安全性与隐私 -> 防火墙 -> 关闭）

## 💡 使用技巧

### Android 手机
1. 用 Chrome 浏览器打开链接
2. 点击右上角 `⋮` 菜单
3. 选择 **"添加到主屏幕"**
4. 桌面会出现一个图标，以后点它直接进！

### iPhone (Safari)
1. 用 Safari 打开链接
2. 点击底部中间的 **"分享图标"** 
3. 下滑选择 **"添加到主屏幕"**
4. 点右上角 **"添加"**
